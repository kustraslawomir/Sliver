# F13 — Onboarding: 3 screens

Depends on: F04, F05

## Goal
Shorter, specific, no generic slides.

## Do
- Screen 1: big slit + 'One clip a day. One film a year.' / 'Catch a moment, keep the best part. SLIVER turns your clips into a film.' → Start.
- Screen 2: 'Name your first project' (field, default 'My 2026') + format cards Cinema 16:9 'for TV & YouTube' / Story 9:16 'for Instagram & TikTok' → Create project.
- Screen 3: 'Camera, please.' / 'SLIVER only records while you tap or hold. Nothing leaves your phone.' → Allow camera (+ mic). Small line: 'Photos and reminders are asked when you need them.' → Camera.
- Contextual permissions: photos on first tap of Add media (pre-prompt sheet); reminders as a card in the Project screen after the 3rd saved clip ('Want a daily nudge?' Set reminder / No thanks).
- Delete the old 7-step onboarding.

## Done when
- [ ] Fresh install reaches recording in 3 taps + 1 permission
- [ ] Build passes
