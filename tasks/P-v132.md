## 2. Daily reminder (v1.3.2) — the main goal
- New screen `Reminders` from Settings -> "Daily reminder" and from the nudge card on the Project screen. REMOVE the old Notifications screen (`feature/notifications/NotificationsScreen.kt` and its route/entries); keep any logic that is reused.
- DataStore: enabled, time (20:00), days[7] (all), skipIfDone (on), lastCall (off, 22:30, only if day empty), followGoldenHour (off; 20 min before evening golden hour, uses the solar code from step 3), projects (open ones, default all).
- Scheduling: one `AlarmManager.setWindow` per next reminder (10 min), no exact alarms (remove SCHEDULE_EXACT_ALARM if still present). Reschedule on boot, timezone change, settings change, after each fire. skipIfDone: at fire time check whether today has a clip in the selected projects; if yes post nothing. Max 2 notifications per day.
- Permission: POST_NOTIFICATIONS requested only when the user turns the reminder on or taps "Set reminder" on the nudge card, never at app start. If Android notifications are off: yellow row with "Turn on" -> `Settings.ACTION_APP_NOTIFICATION_SETTINGS` (`RemindersOff`).
- Notification: channel "Daily reminder", default importance, small icon `ic_stat_sliver`, title "Today's clip", text "<Weekday> is still empty. A few seconds is enough.", large icon = yesterday's clip thumbnail if any. Actions: **Record** (opens camera directly via the existing deep link) and **Tomorrow** (dismiss only).
- Time presets sheet (`RemindersTime`): 6 presets + "Other time..." -> Material 3 TimePicker dialog, 24h/12h from system.
- Light and dark per `Reminders.dc.html` / `RemindersL.dc.html`.
- Unit tests: next-fire computation (days mask, time zone, window), skip logic, max-2/day, lastCall only when empty.
- Device proof: set the reminder 2 minutes ahead on the test device, confirm it fires (`adb shell dumpsys alarm | grep sliver`, `dumpsys notification`), confirm it is skipped when today has a clip, confirm Record opens the camera. Screenshots dark + light next to `design/png` into `docs/qa/reminders-*.png` (no live camera/real media in shots).
