No tab bar. Notification/widget/shortcut/tile record deep links still open the camera directly. Update docs/NAVIGATION.md (camera is now a modal over home, home is root, system Back on home exits).
2. Camera = full-screen modal over home: top-left X closes it (system back too); top-right Light + 3-dots (Grid). REMOVE the project chip and the Today chip from the camera. Save clip -> back to home with today's cell popping in (existing ProjectHubSaved behaviour). Edit clip/Photo clip flow origin = home.
3. Photo/Video: two plain words, no pill; active = white + 4 dp dot underneath, inactive = white 60%; Geist 15/500.
4. Add & Flip: identical controls: 52 dp circle, white 10% fill, 22 dp icon, label under it Geist 12/500 sentence case ("Add", "Flip"). Add is an icon (no thumbnail, no ember + badge).
5. Record glow per tokens.json glow.record: one layer 0 0 12px #FF8A3D4D, breathing peak 0 0 18px #FF8A3D73 (keep the 1.6 s breathing and reduced-motion handling).
6. Month/Year on home: text tabs with a 2 dp underline, no pill.

7. Typography: no Geist Mono and no uppercase labels anywhere in the UI (only the date stamp burned into video stays uppercase mono). Numbers = Geist with `fontFeatureSettings = "tnum"`. Remove mono usage from every screen/token that is not the date stamp; sentence-case all labels (e.g. 'CLIP OK' pill, month headers, section labels, mono meta lines).

9. Settings: "Default film format: Cinema 16:9 >" becomes a normal row that opens a choice (no segmented control). Add Settings > Appearance: System (default) / Light / Dark, persisted in DataStore.
10. Light theme: two ColorSchemes built from tokens.json themeLight / themeDarkMap (add theme tokens to SliverTheme; no screen hard-codes a color; replace remaining hard-coded colors you find). Camera, recording, the Edit clip preview area and the player stay dark in BOTH themes. No glow in light theme. Ember text on light uses emberOnLight #C2540F; ember fills keep #FF8A3D with dark text. Check light boards (ProjectHubL, DayDetailL, ProjectsV2L, SettingsL, EditClipV2L) and status/nav bar icon colors follow the theme.
