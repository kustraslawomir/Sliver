# UX 2026 — what changes and why

## A. Mandatory platform behaviour (Android 16 / targetSdk 36)
- **Orientation lock is ignored on screens ≥ 600 dp** (tablets, unfolded foldables, desktop windows). Apps must work in any orientation and aspect ratio there and survive activity recreation. Phones (< 600 dp) still respect our portrait lock. From API 37 there's no opt-out. → U02
- **Predictive back is on by default**; `onBackPressed` is no longer called. Use `BackHandler` / `PredictiveBackHandler` so sheets, editors and the discard prompt animate with the gesture. → U03
- **Edge-to-edge can't be opted out** on Android 16. Every screen must handle insets (camera under the status bar, controls above the gesture bar). → U03
- **Photo picker is the default way to get media.** Broad media permissions only for apps whose core is managing the library. → U01
- **Progress-centric notifications (Live Updates)** with `Notification.ProgressStyle` (segments, points, tracker icon) are the 2026 way to show long work. → U05

## B. Lessons from award winners
- **Moonlitt** (ADA 2026, Interaction): praised for "an easy onboarding experience" and a "simple to use" interface → first clip in under 30 s, no tutorial screens. → U04
- **Tide Guide** (ADA 2026, Visuals): full-screen visuals "filled with custom animations" → a few signature motions, not motion everywhere (slit loader, clip drop, premiere). → U06
- **Guitar Wiz** (ADA 2026, Inclusivity): Dynamic Type, increased contrast, "Differentiate Without Color" → never rely on ember alone for state. → U09
- **grug** (ADA 2026, Delight) and **Focus Friend** (Play Best App 2025, "a simple yet effective tool that helps you stay present"): one small daily ritual, friendly, nothing extra. Confirms no streaks / no gamification. → U07
- **Luminar** (Play Best Multi-device 2025): works on phone and big screens → U02

## C. Lessons from the direct competitor (1 Second Everyday reviews)
Users complain about: forced vertical-only after a redesign, losing the quick record button, too many taps, can't preview just the chosen second, crashes while saving **with no progress**, **audio drifting out of sync in long films**, the app picking a random part instead of the chosen one, a **non-removable date stamp and end logo**, social/journal pushes, backup behind a paywall.
Users love: turning **Live Photos** into clips, the ritual, auto-fill.
→ We already fixed most of these by design. Still to do: Motion Photos (Android's Live Photos) → U08, frame-exact selection + audio sync tests → U10, quick capture everywhere → U07.

## D. Principles we keep
Dark, one accent, no streaks, offline-first, free, user's own Drive. We don't use Material You dynamic color (brand), but we do follow Material 3 motion, shapes and accessibility guidance.
